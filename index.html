Sıralı liste + dashboard

JSON · CSV · bu dashboard. En sıcak lead'ler tepede, iletişim bilgileriyle hazır.

Özellikler
⚡

Hard 50 Limit

CLI, Apify input ve dataset iterator — üç katmanda clamp. Beklenmedik maliyet yok.

🎯

Akıllı Puanlama

Sektör uyumu ×0.5 + erişilebilirlik ×0.3 + sinyal ×0.2. Toplam 10 üzerinden.

📋

Çoklu Çıktı

JSON, CSV ve bu interaktif dashboard. Filtrelenebilir, sıralanabilir, kopyalanabilir.

🔧

Tek Dosya CLI

Ek backend yok. musteri_ajan.py + requirements.txt yeterli.

Hızlı Başlangıç
# 1) Klonla
git clone https://github.com/furkanalumert1-self/musteribulma
cd musteribulma

# 2) Token ekle
cp .env.example .env
# .env içinde APIFY_API_TOKEN=... satırını doldur

# 3) Bağımlılıkları kur
python3 -m venv .venv
.venv/bin/pip install -q -r requirements.txt

# 4) Claude Code içinde ajanı çağır
claude
